# 800 Verbal

SAT Reading & Writing course website: course information, online applications, and a student area with lessons, practice tests, two full-length mock tests, homework, vocabulary, and progress tracking.

The whole site is one file, `index.html`, and needs no server or database. It is hosted with GitHub Pages.

## Updating the site

Replace `index.html` in this repository with the new version. GitHub Pages republishes it within a minute or two.
